# CodeAlpha_ProjectManager
Task 3 – Project Management Tool (Trello/Asana style). Stack: HTML/CSS/JS, Express.js, SQLite, Socket.io.
Features: auth, group projects with members, task board (To do / In progress / Done), task assignment, task comments, real-time board updates and notifications via WebSockets.
Run: `npm install && npm start` → http://localhost:3002 (open two browsers with different users to see live updates).
